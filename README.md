# EventEase-DB
Relational database system for event, hall, registration, ticket, staff and budget management using SQL Server.

## Project Overview

EventEase DB is a relational database system designed to manage an event operating across multiple halls.

The system handles event sessions, attendee registrations, capacity management, waitlists, QR tickets, check-in and check-out records, staff shifts, approval requests, and budget management.

## Database Scope

The project consists of 12 relational tables:

1. Hall
2. Staff
3. Event
4. Session
5. Attendee
6. Registration
7. Ticket
8. CheckIn
9. Shift
10. Approval
11. Budget
12. Expense

## Core Features

- Role-based access control
- Event and hall management
- Session scheduling
- Attendee registration
- Capacity management and waitlists
- QR ticket management
- Entry and exit tracking
- Live hall headcount calculation
- Staff shift management
- Approval management
- Budget and expense tracking
- SQL reporting views
- Data integrity and constraints
